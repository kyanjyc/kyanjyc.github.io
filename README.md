# KYAN CHEN

解压后，在 Sublime Text 中打开整个文件夹。打开 `index.html` 编辑首页，或在浏览器中双击该文件预览。保留各文件和素材目录的相对位置即可，本地预览无需安装工具或启动服务器。

- `index.html` · 首页
- `work.html` · 作品缩略图
- `about.html` · 个人介绍
- `contact.html` · Email、Instagram 和 LinkedIn
- `projects/` · 各作品的独立 HTML 页面
- `styles.css` · 页面布局、配色和动画
- `type-specimen.css` · 楷书拉丁字样和作品页样式
- `app.js` · 卡片旋转和作品图片放大
- `assets/` · 图片和字体

将上述文件作为网站根目录上传，即可部署到静态托管服务。网站源码仓库中，这些文件位于 `dist/` 下。

从楷书拉丁作品页可以进入 `cry-museum/index.html`，独立博物馆页面包含原有互动。FACET 和 Fortune Stones 的白墙主图另存为 `assets/projects/FACET/FACET_02_WHITE.jpg` 和 `assets/projects/FORTUNE_STONE/FORTUNE_STONE_02_WHITE.jpg`，原照片也在对应素材文件夹内。

MY HAND 白底主图为 `assets/projects/MY_HAND/MY_HAND_03_WHITE.jpg`，同目录保留原照。
